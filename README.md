# Fifty Dimensions for Ten Thousand Senses

Code, corpus generator, pre-registration record, run logs and paper source for
*Fifty Dimensions for Ten Thousand Senses: How a Transformer Packs More Senses
than Width* (Negrescu, 2026; preprint in `paper/`).

**Question.** In $\mathbb{R}^d$ there are exponentially many nearly orthogonal
directions. Superposition theory assumes networks spend that headroom on
near-orthogonal packing. Does a transformer actually do that when it has more
word senses than dimensions?

**Setup.** A synthetic language with $S{=}10^4$ word senses (2000 words × 5
Zipf-ranked senses), known co-activation structure, and a continuation token
recoverable only from the (context cue, word) conjunction. A one-layer
transformer with $d{=}4096$ (no LayerNorm, no positional code, untied
embeddings) is trained on it; geometry is read from per-word-centered residual
activations against matched random baselines.

**Answer.** No. It spends about fifty.

1. The $10^4$ sense centroids occupy a participation ratio of 46–50 dimensions
   out of 4096 (Gaussian reference 2905). The bulk of their non-orthogonality
   is that dimensionality: a spectrum-matched Gaussian null reproduces the
   median deviation (5.4° vs 5.5°). The tail is not: 99.9th percentile 54° vs
   26° under the null, maximum 73° vs 44°.
2. The tail is pairs that share context cues (median 54° vs 5.6° for
   cue-disjoint pairs), and it is inherited from the input: the same pairs are
   already aligned at initialization (17° vs 1.6°, graded in cue overlap), because
   a one-layer bag model sums the cue embeddings into the residual. Training
   amplifies it in step with the compression (ratio ~10× before and after). A
   registered rank-mixed control puts most of it on cue identity and ~5° on rank
   (3 seeds); the rule's subspace clause failed and is reported as such.
3. Width buys dimensions, not accuracy. From $d{=}64$ to 4096 (best of two
   learning rates per width) held-out accuracy is flat at 0.87–0.93, while the
   code SGD builds grows from 7 to 42 effective dimensions (split-half
   noise-corrected), about $d^{0.45}$. Our first sweep read a fixed learning
   rate as a capacity limit; the low-width runs and the rate probes are in
   `DISCOVERY.md`.
4. A training-time interference penalty spreads the code (PR 50 → 76) and
   removes 40% of interference at the median, with no measurable behavioral
   cost; the shared-context tail survives it.
5. Deleting the code's top-variance directions at readout hurts rare senses
   more than a variance-matched random subspace, but every corpus-informed
   basis coincides from $k{\ge}4$, so the ablation names no mechanism. The
   pre-registered fairness check falsified our first reading ("dedicated
   channel"), and an adversarial review round falsified two more: the
   "exact simplex" cosine of $-0.25$ is an identity of per-word centering, and
   "9× less orthogonal than random" was the wrong null, and the shared-cue
   alignment we first read as built by training is present before training. All
   are stated.

## Layout

| path | what |
|---|---|
| `paper/` | LaTeX source (ICLR 2027 format), figure data, `Makefile` (`pdf`, `arxiv`, `lint`, `fmt`, `audit`) |
| `DISCOVERY.md` | pre-registration record: registered design, six numerics amendments with gates, results as they landed, the failed fairness check, toy-arm protocol and caveats |
| `results/TABLES.md` | every number in the paper with its n and seed range; generated by `stats.py` |
| `results/*.log` | raw logs of every run (toy grids, behavioral arms, capacity runs, ablations) |
| `gen.py` | corpus generator with structural self-checks; `check_gen.py` audits task solvability (prior ceiling, order-blind conflicts, split leakage) |
| `model.py`, `harness.py` | from-scratch one-layer transformer; training with the cross-word penalty (`lam`, `pen=coact|uniform`), activation capture |
| `measure.py`, `packing.py`, `posthoc.py` | same-word geometry vs nulls, cross-word packing vs random code, shared-cue / co-occurrence decomposition |
| `run.py`, `sweep.py`, `probe.py` | toy arm ($d{=}64$, CPU, ~1 min/run) |
| `bigrun.py` | capacity arm ($d{=}4096$, one 8 GB GPU, ~15 min train + 1 min analysis) |
| `ablate.py` | readout deletion with the pre-registered fairness controls (`rank`, `cue`, `rare`, `randvar`) |
| `nulls.py` | post-hoc null checks: centering identity, spectrum-matched null, untrained-model baseline, shared/disjoint cue split |
| `splithalf.py` | split-half cross-covariance: participation ratio of the code with measurement noise removed |
| `stats.py`, `figs.py` | tables with spreads and cluster-bootstrap CIs; CSVs for the paper's figures |
| `bench_padskip.py` | numerics gate for Amendment 6 (pad skipping): bitwise loss/residual check and throughput |

## Reproduce

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt   # torch; cu128 wheels for Blackwell
.venv/bin/python gen.py                                              # corpus self-checks: 3 regimes PASS
.venv/bin/python check_gen.py big                                    # task-solvability audit
.venv/bin/python run.py d=64 gamma=0 seed=0 steps=2500               # one toy run, ~1 min CPU
.venv/bin/python bigrun.py seed=0 prec=bf16                          # one capacity run, ~16 min on an RTX 5060 8 GB
.venv/bin/python bigrun.py seed=0 lam=1.0 prec=bf16 pen=uniform      # uniform-priced penalty arm
.venv/bin/python ablate.py seed=0                                    # readout deletion + fairness controls, ~1 min
.venv/bin/python stats.py && .venv/bin/python figs.py                # rewrites results/TABLES.md and paper/data/*.csv
cd paper && make pdf                                                 # needs tectonic (~/.local/bin) or any TeX Live
```

Trained checkpoints (`results/*.ckpt`, 1.2 GB each) and saved centroids
(`results/*.pt`, 160 MB each) are not in git; `stats.py`, `figs.py`,
`posthoc.py` and `ablate.py` read them from `results/`. The checkpoints were
not retained: regenerate them with `bigrun.py` (seeds 0–3 for γ=0; seed 0 for
the two λ=1 arms, ~15 min each) if you want to re-run `ablate.py`, `nulls.py`,
`splithalf.py`, or the unembedding column of T7. Every published table cell
other than that column comes from the logs and centroids.

`stats.py` rewrites `TABLES.md` in place, so without the checkpoints the
unembedding half of T7 comes back empty. The committed `TABLES.md` has those
cells; restore it with `git checkout results/TABLES.md` if you overwrite them.

## Pre-registration

Every design decision, endpoint, decision rule and numerics amendment was
written into `DISCOVERY.md` (or a script header) before the run that used it,
with the date. This repository is published as a snapshot, so those dates are
the author's record rather than an externally timestamped one. Post-hoc
analyses are labelled as such.
